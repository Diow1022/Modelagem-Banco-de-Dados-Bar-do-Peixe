# Modelagem-Banco-de-Dados-Bar-do-Peixe
Criação do Projeto Universitário para Desenvolvimento, Analise de Requisitos e modelagem para Banco de Dados do Bar do Peixe, esse projeto tem como foco ajudar o comercio do bar do peixe a automatizar e inserir banco de dados no comercio, para agilidade de atendimento e controle de estoque.
