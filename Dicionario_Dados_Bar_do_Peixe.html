Projeto de Banco de Dados - Bar do Peixe

Modelo baseado no DER com 13 entidades

1. Apresentação

Este documento apresenta as entidades, atributos, tipos de dados e chaves utilizadas na modelagem do banco de dados do Bar do Peixe.

PK: Chave Primária
FK: Chave Estrangeira
—: Atributo comum

Os tipos SQL são sugestões para uma futura implementação do banco de dados.
